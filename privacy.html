Privacy policy

Last updated 28 October 2026.

RPC Rosters is a private tool run by one household on its own home server. Only the Google account rpc.rosters@gmail.com signs in to it.

What it uses

  • Gmail: reads roster emails forwarded to rpc.rosters@gmail.com, then moves them to Bin. It never sends email.
  • Google Calendar: reads and updates work-shift events on calendars shared with rpc.rosters@gmail.com, only after the calendar owner approves each change.
  • Google Drive: stores the diagram PDFs it creates. It only sees files it created.

What it does with the data

Data stays on the household's home server and in the rpc.rosters@gmail.com Google account. It is not sold, shared with anyone else or used for advertising. Roster files are deleted from the server after 12 weeks.

RPC Rosters' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
